## 🚀 Featured Projects

### Hybrid NFV Orchestrator using OpenStack Service Function Chaining
`OpenStack` `Docker` `Python` `Flask` `Linux` `NFV`
Developed a hybrid NFV orchestrator for automated deployment of Firewall, IDS, and Monitoring VNFs. Implemented resource-aware VNF placement and automated Service Function Chain (SFC) creation using OpenStack Neutron APIs, with a Flask dashboard for end-to-end service chain management.

### OpenStack VM Consolidation and Migration
`OpenStack` `Linux` `Virtualization` `Networking`
Deployed a multi-node OpenStack Dalmatian environment (1 controller, 1 Neutron node, 4–5 compute nodes). Explored predictive VM placement using GRU and ILP for workload consolidation, and performed VM lifecycle management while resolving networking and infrastructure issues in a live virtualized environment.

### Interaction-Aware Sparse-Dense Fusion for Document Clustering
`Python` `PyTorch` `Sentence-Transformers` `Scikit-learn` `UMAP`
Designed a multimodal fusion architecture combining TF-IDF and Sentence-BERT representations via a learned gating mechanism, optimized with Deep Embedded Clustering. Improved Silhouette score from 0.0545 to 0.6135 and achieved 0.986 ARI across 15 independent runs on 20 Newsgroups.

### LHC Canteen Management System
`Node.js` `Express.js` `MongoDB` `Selenium`
Full-stack canteen management system with separate student and staff portals — menu browsing, cart/checkout, live order tracking, and staff-side inventory control. Built REST APIs with Node.js/Express/MongoDB and integrated Selenium-based automated testing for core workflows.
